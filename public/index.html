Timing and missing camera-angle settings

SRT time = video time + offset. For untrimmed matching pairs, leave this at 0. In Folder mode this offset applies to every pair. A clip trimmed 10 seconds from the start typically needs +10.

Default 0 requires the frame time to be inside a valid GPS cue. Unmatched frames are skipped. GPS is never interpolated.

Defaults to assumed −90° (straight down), as requested. Used only when SRT camera pitch is missing and labelled as an assumption. Clear the field to leave pitch unknown. Aircraft pitch is never used.
